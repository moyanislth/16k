# 16K Downloader

16k.club 图片批量下载工具，带 Web 界面。

## 使用

```bash
go run .
```

浏览器打开 http://localhost:8080

## 功能

- **一键下载**：自动翻页下载，直到没有新内容
- **指定页面**：手动输入 page 和 size 参数
- **实时日志**：SSE 推送下载进度和状态
- **中断下载**：Stop 按钮随时取消进行中的任务
- **断点续传**：已下载的图片自动跳过

## 参数

```
-port     服务端口（默认 8080）
-output   图片输出目录（默认 data/temp）
```
